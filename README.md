# LaserVesselHeatLab

LaserVesselHeatLab — приложение на Python для моделирования нестационарного нагрева сосудов кожи импульсным лазером (578 нм и 578+511 нм) в 2D осесимметричной постановке.

Приложение помогает:
- запускать одиночные расчеты;
- прогонять серии кейсов (sweep);
- сравнивать прогоны;
- подбирать параметры через оптимизацию;
- сохранять историю и формировать отчеты.

---

## 1. Установка и запуск

Делаем окружение и ставим зависимости:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
```

Запускаем UI:

```bash
streamlit run app/main.py
```

> Для запуска из PyCharm открываем `app/main.py` и жмем **Run**: скрипт сам переключается на корректный режим `streamlit run ...`.

---

## 2. Быстрый старт (за 2 минуты)

1. Открываем вкладку **Одиночный расчет**.
2. Нажимаем **Загрузить baseline**.
3. Выбираем профиль **Быстрый** (для первичной проверки) или **Точный** (для более качественной картинки).
4. Нажимаем **Запустить**.
5. Смотрим метрики, тепловую карту, графики `T(t)`, профили и анимацию.
6. Выгружаем результаты кнопками **Экспорт CSV** и **Экспорт пакета (zip)**.

## 3. Полный гайд по вкладкам и кнопкам

## Главная

Что делаем:
- открываем приложение и сразу видим сводку по последним расчетам.

Что показывается:

- быстро понять, какие режимы уже считались и какие дали лучший/худший результат.

## Одиночный расчет

Это основная рабочая вкладка для детального анализа одного набора параметров.

### Боковая панель
- **Загрузить baseline** — подгружаем базовый конфиг из `params/baseline.json`.
- **Стоп** — мягко останавливаем текущий расчет.

### Форма параметров
В форме задаем:
- **Геометрию сосуда**: диаметр `D`, глубина.
- **Лазер**: режим (`578` или `578_511`), `tp`, `f`, `w0`, `A578/A511`, `mu578/mu511`, доля `p578`.
- **Режим расчета**: `Быстрый` или `Точный`.
- **Перфузию**: включаем/выключаем.

### Кнопка
- **Запустить** — считаем задачу и сохраняем прогон в базу.

### После расчета смотрим
- JSON с метриками;
- тепловую карту `T(r,z)` с выбором момента времени;
- график `T(t)` в центре и у стенки сосуда;
- профиль `T(r)` на глубине сосуда;
- профиль `T(z)` на оси;
- анимацию тепловой карты по времени;
- таблицу временного ряда.

### Экспорт
- **Экспорт CSV** — забираем временной ряд;
- **Экспорт пакета (zip)** — забираем артефакты прогона целиком.

---

## Пакетный расчет

Эта вкладка нужна для серии автоматических расчетов по таблице кейсов.

Что делаем:
1. Открываем `data/sweeps.csv` в редакторе прямо в UI.
2. Добавляем/меняем строки параметров.
3. Выбираем число процессов.
4. Нажимаем **Запустить sweep**.

Что получаем:
- итоговую таблицу по всем кейсам;
- `heatmap` равномерности по `(D, depth)`;
- 3D-график `(tp, f) -> UniformityIndex`;
- Pareto-график `UniformityIndex vs Tmax`.

Экспорт:
- **Скачать sweep CSV**.

---

## Сравнение

Здесь сравниваем несколько ранее сохраненных прогонов.

Что делаем:
1. Выбираем 2–5 прогонов.
2. Смотрим наложение кривых `T(t)`.
3. Смотрим сравнительную таблицу метрик.
4. Для первых двух прогонов анализируем разностную карту температур.

Зачем:
- быстро увидеть, какой набор параметров дает более ровный нагрев и где появляются перегретые зоны.

---

## Оптимизация

### Что это такое
Сейчас используется **random search** (случайный поиск), а не «тяжелая» байесовская оптимизация.

Логика:
- случайно выбираем параметры в заданных диапазонах;
- запускаем модель;
- считаем метрики;
- минимизируем `UniformityIndex` при ограничении `Tmax_vessel < Tmax_limit`.

### Что делаем
1. Выставляем ограничение **Ограничение Tmax [K]**.
2. Выставляем число итераций.
3. Нажимаем **Запустить оптимизацию**.

### Что получаем
- таблицу лучших кандидатов;
- график сходимости `score`.

### Когда подходит
- подходит для первичного подбора и грубой навигации по параметрам;
- для финальной инженерной настройки обычно делаем более узкий ручной донастрой или расширяем метод оптимизации.

## Отчет

Что делаем:
1. Выбираем прогон из списка.
2. Нажимаем **Сформировать HTML-отчет**.
3. Скачиваем отчет кнопкой **Скачать отчет**.

Что внутри отчета:
- параметры;
- метрики;
- ссылка на папку артефактов.

---

## 4. Что означают основные метрики

- `Tmax_vessel` — максимальная температура в сосуде.
- `Tmin_vessel` — минимальная температура в сосуде.
- `Tmean_vessel` — средняя температура в сосуде.
- `Std_vessel` — стандартное отклонение температуры по сосуду.
- `UniformityIndex = (Tmax - Tmin) / Tmean` — чем меньше, тем равномернее нагрев.
- `WallCoreDelta` — разность температуры стенка минус центр.
- `HotSpotFraction` — доля объема/площади сосуда выше порога.
- `TimeToThreshold` — время достижения порога по среднему нагреву сосуда.

---

## 5. Почему тепловая карта может выглядеть «странно»

Обычно причина в одном или нескольких пунктах:
- выбран **Быстрый** профиль (грубая сетка);
- слишком крупный `dt`;
- параметры `A`, `mu`, `w0`, `tp`, `f` заданы в неудачном сочетании;
- сравнение идет на неподходящем индексе времени.

Что делаем для адекватной картинки:
1. Переключаемся на профиль **Точный**.
2. Проверяем диапазоны параметров (см. ниже).
3. Смотрим не только теплокарту, но и `T(t)`, профили `T(r)`/`T(z)` и метрики.
4. Сначала подбираем режим через sweep, потом уточняем одиночным расчетом.

---

## 6. Рекомендуемые диапазоны параметров

- Диаметр сосуда `D`: **30–200 мкм**
- Глубина `depth`: **0.2–1.5 мм**
- Длительность импульса `tp`: **0.1–5 мс**
- Частота `f`: **1–50 Гц**
- Радиус пучка `w0`: **0.2–2 мм**
