# LaserVesselHeatLab

LaserVesselHeatLab — Python-приложение для моделирования нестационарного нагрева сосудов кожи импульсным лазером (578 нм и режим 578+511 нм) в 2D осесимметричной постановке, с UI, аналитикой, sweep, сравнением, оптимизацией и отчетами.

## Установка и запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
streamlit run app/main.py
```

> Важно: не запускайте `python app/main.py` как обычный скрипт. Для Streamlit нужен именно запуск через `streamlit run ...`.

## Что внутри
- **Streamlit UI (на русском)**: Dashboard, Одиночный расчет, Sweep, Сравнение, Оптимизация, Отчет.
- **PDE модель**: Pennes био-теплоперенос + лазерный источник + неявная схема Backward Euler.
- **SciPy sparse**: сборка и решение разреженной системы, кеш-факторизация.
- **SQLite**: история запусков и метрик.
- **Экспорт**: CSV и ZIP-пакет артефактов запуска.

## Sweep
1. Откройте страницу **Sweep / Пакетный расчет**.
2. Загрузите/отредактируйте `data/sweeps.csv`.
3. Нажмите **Запустить sweep**.
4. Получите итоговую таблицу, heatmap, 3D аналитику и Pareto-график.

## Результаты
- БД: `results/laservesselheatlab.sqlite`
- Запуски: `results/runs/run_<id>/`
  - `params.json`
  - `metrics.json`
  - `series.csv`
  - `fields.npz`
- Отчеты: `results/reports/*.html`

## Рекомендуемые диапазоны параметров
- Диаметр сосуда **D**: 30–200 мкм
- Глубина **depth**: 0.2–1.5 мм
- Длительность импульса **tp**: 0.1–5 мс
- Частота **f**: 1–50 Гц
- Радиус пучка **w0**: 0.2–2 мм

## Дисклеймер
Модель упрощенная (по сравнению с полнофункциональными FEM-пакетами), но пригодна для сравнительного анализа режимов облучения и подбора параметров.
